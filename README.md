Gobble Dash — a complete, original turkey escape game that plays offline in a desktop browser from its own files. A turkey runs 6000 m through farmyard, barn and kitchen, dodging fences, ovens and falling carving knives while the farmer chases, searches and corners it, and escapes through the forest gate. An AI judge compares the games two at a time, places go by win rate, and the 20 best share $250.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
